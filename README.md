# QuickServer

A lightweight and portable Nginx + PHP + MariaDB + PostgreSQL + Redis environment for Windows.

## Features

- **Nginx** - High performance web server
- **PHP** - Server-side scripting language
- **MariaDB** - MySQL-compatible database server
- **PostgreSQL** - Advanced open source database
- **Redis** - In-memory data structure store

## Prerequisites

- Windows Vista/Server 2008 x64 or higher version
- Requires Administrator Rights
- [Visual Studio C++ 2019 (x64) Redistributable](https://go.microsoft.com/fwlink/?LinkId=746572)
- [.NET Framework 4.6](https://www.microsoft.com/en-us/download/details.aspx?id=48130)

## Installation

1. Download the latest version of QuickServer
2. Extract to your desired location
3. Run `QuickServer.exe`
4. Click the "Start All" button to start all services

## Default Credentials

- **MariaDB**: user: `root`, password: `root` (recommended to change)
- **PostgreSQL**: user: `postgres`, password: `postgres` (recommended to change)

## Notes

- Change the default database passwords for security
- SSL certificates are automatically generated
- Configuration files can be edited through the control panel
